# Contributing ✨

Pull requests are welcome!

## Ways to contribute

- Fix bugs or add features.
- Add or improve tests.
- Clarify documentation and examples.

## Before you start

For larger changes, please open an issue first to discuss your proposal.

## Opening a pull request

Keep changes focused and explain what they improve. Include relevant tests or
documentation updates where appropriate.

See the [README](README.md) for installation, usage, and examples.
